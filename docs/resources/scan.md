# tenableio_scan (Resource)

Manages a scan configuration in Tenable.io.

## Example Usage

```terraform
data "tenableio_scan_template_tenable" "basic" {
  title = "Basic Network Scan"
}

data "tenableio_scan_template_tenable" "advanced" {
  title = "Advanced Network Scan"
}

# On-demand scan targeting specific IPs
resource "tenableio_scan" "assessment" {
  template_uuid = data.tenableio_scan_template_tenable.basic.uuid
  name          = "central-region-assets"
  text_targets  = "192.0.2.1-192.0.2.255"
  emails        = "[email protected]"
}

# Recurring weekly scan using a custom policy
resource "tenableio_scan" "weekly" {
  template_uuid    = data.tenableio_scan_template_tenable.advanced.uuid
  name             = "western-region-weekly"
  text_targets     = "10.0.0.0/24"
  policy_id        = tenableio_scan_template_custom.internal.id
  enabled          = true
  launch           = "WEEKLY"
  starttime        = "20240101T130000"
  rrules           = "FREQ=WEEKLY;INTERVAL=1;BYDAY=MO"
  timezone         = "US/Mountain"
  scan_time_window = 180
}
```

## Schema

### Required

- `name` (String) The name of the scan.
- `template_uuid` (String) The UUID of the scan template to use.

### Optional

- `description` (String) The description of the scan.
- `emails` (String) Comma-separated list of email addresses to notify on scan completion.
- `enabled` (Boolean) Whether the scan schedule is enabled.
- `file_targets` (String) Name of an uploaded file containing scan targets.
- `folder_id` (Number) The ID of the folder to store the scan in.
- `launch` (String) Launch schedule type: ON_DEMAND, DAILY, WEEKLY, MONTHLY, YEARLY. Defaults to whatever Tenable.io assigns when omitted.
- `policy_id` (Number) The ID of the policy to use for the scan.
- `rrules` (String) Recurrence rules for the scan schedule (iCal RRULE format).
- `scan_time_window` (Number) Maximum time window in minutes for the scan to run.
- `scanner_id` (Number) The ID of the scanner to use.
- `starttime` (String) The start time for the scan schedule (format: YYYYMMDDTHHmmss).
- `tag_targets` (List of String) List of tag UUIDs identifying assets to scan.
- `text_targets` (String) Comma-separated list of targets to scan (IPs, hostnames, CIDR ranges).
- `timezone` (String) The timezone for the scan schedule.

### Read-Only

- `creation_date` (Number) Unix timestamp when the scan was created.
- `id` (Number) The unique identifier for the scan.
- `last_modification_date` (Number) Unix timestamp when the scan was last modified.
- `status` (String) The current status of the scan.
- `uuid` (String) The UUID of the scan (assigned by Tenable.io).
