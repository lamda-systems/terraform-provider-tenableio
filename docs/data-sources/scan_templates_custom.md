# tenableio_scan_templates_custom (Data Source)

Lists the user-defined scan templates -- Scan Templates > User Defined in the Tenable.io UI, which the API calls policies -- that the API keys can see. To pick one, `tenableio_scan_template_custom` looks it up by name or id.

## Example Usage

```terraform
# Every user-defined scan template the API keys can see.
data "tenableio_scan_templates_custom" "all" {}

output "custom_template_ids" {
  value = { for t in data.tenableio_scan_templates_custom.all.templates : t.name => t.id... }
}
```
