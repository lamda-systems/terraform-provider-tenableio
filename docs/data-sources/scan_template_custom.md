# tenableio_scan_template_custom (Data Source)

Looks up a user-defined scan template -- one listed under Scan Templates > User Defined in the Tenable.io UI, which the API calls a policy -- by its name or its id. Use its `id` as the `policy_id` of a `tenableio_scan`. The lookup fails unless exactly one template matches.

## Example Usage

```terraform
# A template built in the Tenable.io UI (Scan Templates > User Defined),
# looked up by the name it was given there.
data "tenableio_scan_template_custom" "credentialed" {
  name = "Internal - Credentialed"
}

# Names need not be unique in Tenable.io. When two templates share one, the
# lookup fails and lists them with their ids; look the right one up by id.
data "tenableio_scan_template_custom" "legacy" {
  id = 45
}

data "tenableio_scan_template_tenable" "advanced" {
  title = "Advanced Network Scan"
}

resource "tenableio_scan" "weekly" {
  template_uuid = data.tenableio_scan_template_tenable.advanced.uuid
  policy_id     = data.tenableio_scan_template_custom.credentialed.id
  name          = "internal-weekly"
  text_targets  = "10.0.0.0/24"
}
```

## Schema

### Optional

- `id` (Number) The template's id. Exactly one of `id` and `name` must be set.
- `name` (String) The template's name, matched exactly, including case. Exactly one of `id` and `name` must be set. Tenable.io does not require names to be unique; when two templates share one, look the template up by `id` instead.

### Read-Only

- `creation_date` (Number) Unix timestamp when the template was created.
- `description` (String) The template's description. Null when Tenable.io reports none.
- `last_modification_date` (Number) Unix timestamp when the template was last modified.
- `owner` (String) Username of the template's owner.
- `owner_id` (Number) Id of the template's owner.
- `shared` (Boolean) Whether the template is shared with users other than its owner.
- `template_uuid` (String) The uuid of the Tenable-provided template this one is based on, from the policy template list (see `tenableio_policy_template_tenable`).
- `visibility` (String) `private` or `shared`.
