# tenableio_scan_templates_tenable (Data Source)

Lists the Tenable-provided templates in the `scan` template list. To pick one template, `tenableio_scan_template_tenable` looks it up by name or title.

## Example Usage

```terraform
# Every Tenable-provided template a scan can be created from.
data "tenableio_scan_templates_tenable" "all" {}

output "scan_template_names" {
  value = { for t in data.tenableio_scan_templates_tenable.all.templates : t.name => t.title }
}
```
