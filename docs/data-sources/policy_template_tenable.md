# tenableio_policy_template_tenable (Data Source)

Looks up a Tenable-provided template from the `policy` template list by its name or its title, instead of by uuid. Use its `uuid` as the `template_uuid` of a `tenableio_scan_template_custom`. The lookup fails unless exactly one template matches.

## Example Usage

```terraform
# The base of a user-defined scan template comes from the policy list, not the
# scan list: the same template can have a different uuid in each.
data "tenableio_policy_template_tenable" "advanced" {
  title = "Advanced Network Scan"
}

resource "tenableio_scan_template_custom" "internal" {
  template_uuid = data.tenableio_policy_template_tenable.advanced.uuid
  name          = "Internal - Baseline"
}
```

## Schema

### Optional

- `is_agent` (Boolean) Whether the template is for agent scans. Set it to narrow a lookup whose title matches both a network and an agent template. Tenable.io reports null for non-agent templates; that is exposed as `false`.
- `name` (String) The template's short system name, such as `advanced` or `agent_basic`. Exactly one of `name` and `title` must be set. Matched case-insensitively.
- `title` (String) The template's name as the Tenable.io UI shows it, such as `Advanced Network Scan`. Exactly one of `name` and `title` must be set. Matched case-insensitively. Some titles are shared by a network and an agent template; set `is_agent` to choose between them.

### Read-Only

- `cloud_only` (Boolean) Whether the template is available only in the cloud.
- `description` (String) What the template is for.
- `is_was` (Boolean) Whether the template is only for Tenable Web App Scanning. Null from Tenable.io is exposed as `false`.
- `manager_only` (Boolean) Whether only a manager can use the template.
- `order` (Number) Display order in the Tenable.io UI. Null when Tenable.io reports none.
- `subscription_only` (Boolean) Whether the template is available only to subscribers.
- `unsupported` (Boolean) Whether the template is unsupported.
- `uuid` (String) The template uuid.
